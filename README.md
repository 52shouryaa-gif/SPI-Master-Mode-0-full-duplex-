# SPI Master — Verilog RTL

A parameterized SPI Master core written in Verilog, supporting full-duplex (simultaneous MOSI/MISO) transfers in **SPI Mode 0** (CPOL = 0, CPHA = 0), with a configurable clock divider and a self-checking testbench that simulates an external SPI slave.

## Features

- Full-duplex transfer — shifts data out on `MOSI` and captures data on `MISO` in the same 8-clock transaction
- SPI Mode 0: data sampled on the rising edge of `spi_clk`, shifted on the falling edge
- MSB-first bit order
- Parameterizable clock divider (`clock_per_half_bit`) — sets how many system clock cycles make up half an SPI clock period
- Simple host interface: `tx_data` / `tx_valid` in, `rx_data` / `rx_valid` out, `busy` status flag
- 3-state FSM: `idle → transfer → done`

## Port List

| Signal          | Dir | Width | Description                                      |
|-----------------|-----|-------|---------------------------------------------------|
| `clk`           | in  | 1     | System clock                                       |
| `rst_n`         | in  | 1     | Asynchronous reset, active low                     |
| `tx_data`       | in  | 8     | Byte to transmit                                   |
| `tx_valid`      | in  | 1     | Pulse high for 1 cycle to start a transfer         |
| `rx_data`       | out | 8     | Byte received from the slave                       |
| `rx_valid`      | out | 1     | Pulses high for 1 cycle when `rx_data` is valid    |
| `busy`          | out | 1     | High while a transfer is in progress               |
| `spi_mosi`      | out | 1     | Master Out, Slave In                               |
| `spi_clk`       | out | 1     | SPI clock, generated by the master                 |
| `spi_miso`      | in  | 1     | Master In, Slave Out                               |
| `spi_cs_n`      | out | 1     | Chip select, active low                             |

**Parameter:** `clock_per_half_bit` (default `4`) — number of `clk` cycles per half SPI-clock period. Total SPI clock period = `2 × clock_per_half_bit` system clocks.

## How It Works

1. **Idle** — `spi_cs_n` held high, waiting for `tx_valid`. On assertion, `spi_cs_n` drops low, the MSB of `tx_data` is pre-loaded onto `spi_mosi`, and the FSM moves to `transfer`.
2. **Transfer** — a clock divider counts `clock_per_half_bit` system cycles per half-period, toggling `spi_clk`. Each rising edge samples `spi_miso` into the RX shift register; each falling edge shifts the next TX bit onto `spi_mosi`. Repeats for all 8 bits.
3. **Done** — `spi_cs_n` is deasserted, `rx_data` is latched from the shift register, `rx_valid` pulses high, `busy` drops, and the FSM returns to `idle`.

## Repo Contents

| File                | Description                                                        |
|---------------------|----------------------------------------------------------------------|
| `spidesign.v`       | SPI master RTL                                                      |
| `testspi.v`         | Self-checking testbench — sends `0xC3`, simulates a slave replying with `0xA5`, and checks `rx_data` |
| `spi_sim.vvp`       | Compiled simulation binary (Icarus Verilog)                         |
| `gtkwave.vcd`       | Waveform dump from the testbench run                                |
| `spi_proto.gtkw`    | Saved GTKWave signal layout for quick waveform inspection            |

## Simulation

```bash
iverilog -o spi_sim.vvp spidesign.v testspi.v
vvp spi_sim.vvp
gtkwave gtkwave.vcd spi_proto.gtkw
```

Expected output:

```
SUCCESS: Master received correct data from slave (0xa5)
```
